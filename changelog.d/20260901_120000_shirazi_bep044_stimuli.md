### Added

- Support for BEP044 stimulus organization in `/stimuli`:
  files are validated when a `/stimuli/stimuli.tsv` catalog is present
  (legacy free-form stimuli directories remain exempt), and
  `UNUSED_STIMULUS` recognizes catalog-tracked stimuli.

### Fixed

- Stimulus file rules (datatype `stimuli`) only match files under
  `/stimuli` in datasets that have a `/stimuli/stimuli.tsv` catalog. Previously any
  file whose suffix was `audio`, `image`, `video` or `audiovideo` was matched
  by suffix alone, so legacy stimuli such as `/stimuli/cm4_audio.wav`
  (bids-examples `ieeg_filtered_speech`) were reported as malformed BEP044
  names, and `stim-<label>_image.png` outside `/stimuli` was accepted.
